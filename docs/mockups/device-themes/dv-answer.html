THRASHER THEME

Answering Machine

A beige 1980s answering machine on the hall table. Every clip is a message waiting for you.

  • Red seven segment counter shows how many clips you have and the NEW light blinks
  • Big red REC key records, LOAD imports a file, ASK opens chat, MINI is widget mode, SET is settings
  • Clips become a numbered message log, the selected one lights up as message 2 of 8
  • PLAY key and tape slider sit in the footer, wide view moves LOAD ASK MINI beside REC on the machine
