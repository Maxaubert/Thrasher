THRASHER THEME

Brick Phone

Thrasher as a chunky late 90s handset. The app lives on an amber backlit LCD and the keys do the work.

  • Green call key records and red end key stops or goes back
  • Menu soft key opens settings and Find jumps to Search
  • Keys 1 2 3 are import ask and widget with backlit icons
  • Nav rocker scrolls the clip inbox and its centre plays
  • Input level is the classic signal bars icon
  • Wide view turns the handset sideways like a game phone
