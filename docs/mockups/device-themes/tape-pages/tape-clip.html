THRASHER THEMETape Deck clip pages

The clip page loads the clip into the deck like a cassette. Transport, counter and tape path sit on the aluminium faceplate, the transcript is the typed insert card from the case, and every popup is a cream index card.

PAGE 1One clip

The clip is the cassette in the deck: its name is written on the label, and the deck plays it.

  • Back to Clips is an Eject key in the title bar
  • Rename and Delete are small keys beside the tape counter
  • The waveform is the tape path with brass splice tabs as trim handles
  • Speed is a lit five step selector and Loop a latching key with a lamp
  • Transcript is the typed J card insert with a key rail above it
  • Export is the amber key in the walnut footer, status sits in a readout strip

PAGE 1 EDITEdit transcript

The insert card rolls into the typewriter: the same card, now an amber framed sheet you type on.

  • Card gets an amber frame and the caret is an amber typebar line
  • Pause tags are typed in amber like corrections
  • The change count is a red rubber stamp on the rail
  • Cancel and Save replace the rail keys, playback stops
  • Unsaved changes and Speaking new words are index cards over a dimmed deck

PAGE 5Merge

A splicing bench: the picked tapes lie in a row, you shuffle them, then splice them into one new cassette.

  • Order rows are tape spines with a grip, an amber place number and a play knob
  • Remove is a small x at the end of each spine
  • The new name is written on a blank cassette label
  • Merge is the red key, Cancel a plain key, both in the footer
  • Wide puts the splicing block and the name on the left deck panel
